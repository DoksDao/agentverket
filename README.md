# Agentverket

Agentverket is a platform for Norwegian SMBs.

Customers log in to access specialized AI employees that perform specific business tasks such as:
- generating offers
- analyzing leads
- summarizing meetings
- creating reports

The MVP focus is frontend structure and product experience.
No real AI backend is required yet.
Use mock data first.

## MVP pages
- Login
- Dashboard
- AI Employees
- Task Runner
- Activity
- Integrations

## Product goal
The platform should feel like an AI operating system for small businesses.
It should not feel like a generic AI chat application.
